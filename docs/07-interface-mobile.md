# 07 — Interface et contrôles tactiles

## Gestes (mode caméra)
| Geste | Action |
|---|---|
| Glisser 1 doigt | déplacer la caméra |
| Pincer | zoom |
| 2 doigts qui tournent / glissent verticalement | pivoter / incliner |
| Tap | sélectionner (lutin, objet, établi) |
| Appui long | menu contextuel |

## Mode construction (pose « à la Minecraft »)
1. Ouvrir **Construire**, choisir le matériau.
2. **Tap sur la face d'un bloc** → bloc-plan collé à cette face (aperçu de la face visée en surbrillance avant de lever le doigt).
3. **Glisser** depuis une face → ligne ; boutons **Remplir** (rectangle) et **Mur** (avec hauteur).
4. **Gomme** pour retirer ; **Annuler / Rétablir** toujours visibles.
5. Pendant le mode construction, **1 doigt = construire**, **2 doigts = caméra** (pour ne pas poser par erreur).
6. **Curseur d'étage** sur le bord droit : glisser pour masquer les étages supérieurs.

## Mode récolte (menu Récolter)
1. Choisir l'ordre : Couper · Creuser (trou / mine / puits) · Cueillir · Chasser · Pêcher.
2. **Tap** = cercle de sélection ; **curseur de rayon 1 → 20 cases** ; tout ce qui se récolte dedans est marqué.
3. Creuser : sélection 3D bloc par bloc ou par cube ; puits = colonne 1×1 jusqu'à la nappe.
4. Bouton **Assigner** : choisir les lutins qui font cette tâche (liste avec métier et niveau).

## Écran principal (paysage)
- **Haut** : jour/saison, vitesse, population, ressources (Nourriture = total des aliments, bois, pierre, fer, or ; chaque case ouvre un **menu déroulant** de détail), **cloche d'alerte**, **engrenage**.
- **Bas** : Construire · Récolter · Zones (champs, réserve, chasse) · Lutins (métiers) · **Militaire** · **Commerce** · Gestion.
- **Droite** : panneau de la sélection (repliable) + curseur d'étage.
- **Engrenage** : Reprendre, Sauvegarder, Charger, Paramètres (son, graphismes, langue, taille des textes), Menu principal, Quitter.
- **Dialogues** : boîtes d'événement (portrait, texte sur parchemin, 2-3 choix), ex. un marchand arrive.
- **Menu principal** : Continuer, Nouvelle partie (Bac à sable / Aventure Royale, graine de carte), Charger, Paramètres, Crédits, Quitter.
- Style (v2, en validation) : cadres de fer sombre à filets dorés, parchemin vieilli, titres en Cinzel.
- Zones tactiles ≥ 48 dp ; jamais plus de 2 niveaux de menu pour une action fréquente.
